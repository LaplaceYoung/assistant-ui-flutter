## The four partial elements, and why

| Element | What is missing | Why it stays partial |
|---|---|---|
| `markdown-text` | Mermaid diagram types outside the flowchart subset (sequence, class, state, gantt, pie) and LaTeX outside the typesetter's grammar | The flowchart painter and the typesetter are Dart implementations, so the *element* works without a host engine; the remainder are separate engines upstream (Mermaid is JS, KaTeX has no Dart port) |
| `web-preview` | The frame on non-web platforms | The element's chrome is ported in full and enforces no isolation, exactly as upstream documents; on web the frame is a sandboxed iframe registered as a platform view, elsewhere the host supplies one |
| `attachment` | A concrete storage backend | Upstream leaves uploads to the app through `AttachmentAdapter`; the port ships the same contract, progress, preview and remove |
| `file` | A host-provided download action | The chip renders the mime icon set, the type label and the payload size; opening the payload needs an app dependency (`url_launcher` or a save dialog), which belongs to the host |

## The one partial package

`react-native` — its 43 element files were used as the layout reference for the
Flutter widgets rather than ported file by file. The elements themselves are
covered by `doc/element-coverage.md`.

## n/a packages

22 of the 46 upstream packages are build tooling (`metro`, `next`, `vite`,
`x-buildutils`, `x-changelog`, `x-generative-compiler`, `x-performance`, `cli`,
`create-assistant-ui`), other framework bindings (`svelte`, `vue`, `react-ink`,
`react-ink-markdown`), or React-only surfaces (`react-hook-form`, `react-lexical`,
`react-streamdown`, `react-devtools`, `agent-launcher`'s build wiring,
`safe-content-frame`, `mcp-docs-server`, `eve`). Each carries its reason in
`doc/package-coverage.md`.

## Not claimed

- The motion work is class-level (durations, curves, offsets) plus behaviour
  assertions and phase-level browser frames. It is **not** a frame-by-frame diff
  against the live site; `doc/MOTION_PLAN.md` states this.
- The landing's residual 3.6% pixel difference is font rasterisation (the bundled
  Public Sans renders ~10% wider), the demo panel's scripted animation and the
  dotted art — not layout drift.
- The web iframe path is compile-verified and covered by its host contract; the
  VM tests exercise the stub, not a browser iframe.
